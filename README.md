# Melkamu Wale — Creative Portfolio 🎨

A modern, responsive portfolio for Melkamu Wale, a professional Graphics Designer & Video Editor. 

This project showcases expertise in logo design, branding, social media graphics, and video production through a sleek, highly interactive user interface.

## ✨ Features

- **Dynamic Theme Support:** Full light & dark mode capability built with semantic CSS variables.
- **Beautiful Animations:** Smooth page transitions, scroll animations, and interactive hover effects powered by Framer Motion.
- **Responsive Layout:** Perfectly tailored for desktop, tablet, and mobile devices using Tailwind CSS.
- **Categorized Portfolio:** Interactive filter system for separating Logo Design, Social Media, Posters, and Video Editing projects.
- **Fast Performance:** Optimized image loading and static assets handled seamlessly by Next.js.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** Custom SVGs and Emojis
- **Language:** TypeScript

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

- `/app`: Contains the Next.js App Router layout, global CSS, and main page logic.
- `/components`: Houses modular UI components (Hero, About, Portfolio, Services, Testimonials, Contact, Footer).
- `/public`: Static assets including images and logos.
